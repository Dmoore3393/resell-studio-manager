# Resell Studio

A mobile-friendly reselling manager with inventory, item IDs, owner-separated profits, sales, payouts, and JSON/CSV backups.

## Privacy
This is a browser-local application. All user-entered data and uploaded photos are saved only to the browser localStorage. The public website does not include any real inventory records, family data, or buyer details, and there is no account or cloud sync.

## Important
Back up regularly using Settings > Export backup. Browser storage can be erased; backups can be restored using Import inventory.
